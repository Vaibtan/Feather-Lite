# Phase 1.5 — voice tracer bullet: findings

**Date:** 2026-08-16 · **Stack:** `@livekit/agents@1.6.4` (Node 22, Windows), LiveKit Cloud Build plan (region India West), Inference STT `deepgram/nova-3` + TTS `cartesia/sonic-3`, silero VAD, multilingual turn detector · **Code:** `apps/voice-worker/src/tracer/`

## Result

D2 ("the voice worker's `llmNode` *is* the control plane") is **proven end-to-end on the real stack**, twice:

- `text-run.ts` — framework testing harness (`session.run({userInput}).wait()`), no audio: 3 turns incl. a tool-mode turn (no model text; `say` frames only) and end-of-call shutdown. **This is the seed of the voice/simulation equivalence test (rev.2 R16).**
- `fake-borrower.ts` — headless borrower that *speaks* (Inference TTS → published mic track) and listens to the agent's transcript text stream: a **51.8 s fully automated voice call**: non-interruptible Mini-Miranda → STT `"Yes. This is Jordan."` → streamed reply **barged in and truncated** (`heard="Thank you for confirming. I'm calling about your account with a balance"`) → deterministic read-back → `"Yes. That's correct."` → confirmation spoken after "commit" → room deleted (hangup). Exit code 0.

## What we learned (each changes the design or the plan)

| # | Finding | Consequence |
|---|---|---|
| 1 | `Agent.llmNode(chatCtx, toolCtx, modelSettings): Promise<ReadableStream<ChatChunk \| string \| FlushSentinel> \| null>` — bare strings are accepted (reviewer's claim otherwise was wrong for JS 1.6). | Worker streams control-plane text deltas directly. |
| 2 | `generateReply` throws `"trying to generate reply without an LLM model"` before reaching `llmNode`. | A placeholder `RemoteOrchestratorLLM` whose `chat()` throws satisfies the guard *and* proves `llmNode` is the only reply path. |
| 3 | WHATWG `ReadableStream`: a `pull()` that resolves without enqueuing is **not re-invoked** (no read pending → no `pullAgain`). Turns made only of `say`/`turn_end` frames stalled in "thinking". | `pull` loops until it enqueues a delta or the frames end. |
| 4 | `session.say(text, {allowInterruptions})` from *inside* `llmNode` queues a separate `SpeechHandle` that plays **after** the generated reply, in order. Empty replies complete cleanly. | Read-backs / confirmations are `say` frames; the frame protocol `turn_start / delta* / say* / turn_end` works as designed (rev.2 R5). |
| 5 | Barge-in: the framework truncates the assistant `ChatMessage` to what was heard and sets `interrupted: true`; the next `llmNode` sees it in `chatCtx`; `conversation_item_added` fires with the truncated item. | `AGENT_TURN_PLAYOUT{heard_text, interrupted}` is sourced from `conversation_item_added` (assistant role). |
| 6 | **User turns that complete during a non-interruptible segment are dropped** (`WARN skipping user input, current speech generation cannot be interrupted`), even with `discardAudioIfUninterruptible: false` (audio is kept, STT runs, end-of-turn is skipped). | Disclosures stay non-interruptible (legal). **Read-backs become interruptible**; the control plane records a promise only if the read-back was **fully heard** (`AGENT_TURN_PLAYOUT.interrupted === false` or `heard_text` contains amount+date), otherwise it re-reads. Add scenario `read-back-interrupted-is-repeated`. |
| 7 | `preemptiveGeneration` is configured under `turnHandling: { preemptiveGeneration: { enabled: false } }` (top-level option deprecated). | Set exactly so (rev.2 R2). |
| 8 | `userAwayTimeout` (12 s) fires `user_state listening -> away`; it also fires between turns if the borrower is slow. Participant disconnect closes the session (`participant_disconnected`). | Worker: `away` → `no_input` signal (2-strike, own counter); disconnect → `hangup` signal. |
| 9 | `session.shutdown()` does not remove the agent from the room; **hangup = `ctx.deleteRoom()`** (disconnects browser/SIP participant, ends the job). | Worker calls `ctx.deleteRoom()` on session close after final playout. |
| 10 | Per-job process cold start on Windows/tsx exceeded the 10 s default → `runner initialization timed out`. With `numIdleProcesses: 1, initializeProcessTimeout: 60_000`: agent joins ~3.0 s after dispatch, first audio at ~3.4 s. | Keep those `ServerOptions`; document. |
| 11 | Inference STT/TTS work on the free Build plan (India West). Agent transcripts are published as `lk.transcription` delta text streams (`registerTextStreamHandler`), which the fake borrower uses for timing. | Console can render live transcripts from the same stream. |
| 12 | Metrics events (`metrics_collected`): `tts_metrics{ttfbMs,durationMs,audioDurationMs,charactersCount,speechId}`, `stt_metrics{durationMs,audioDurationMs}`, `eou_metrics{endOfUtteranceDelayMs,transcriptionDelayMs,onUserTurnCompletedDelayMs,speechId}`, `interruption_metrics`. | Latency waterfall (rev.2 R21) = eou → control-plane TTFT (ours) → TTS `ttfbMs`. |
| 13 | `voice.AMD(session, {participantIdentity}).execute()` exists (`AMDCategory.HUMAN|MACHINE_VM|MACHINE_IVR|MACHINE_UNAVAILABLE|UNCERTAIN`). | Phase 5 SIP path per rev.2 R9. |
| 14 | `RunResult` is not thenable in 1.6.4 — use `.wait()`. Text-mode sessions need `initializeLogger`. | Test harness detail. |
