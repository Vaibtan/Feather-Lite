# Handoff

Read the current task state and relevant artifacts. Write a concise continuation note at the requested destination; otherwise use docs/plans with a descriptive filename.

Include the objective, decisions and approvals, completed changes, current Git state, validation results, blockers, and the next actionable steps. Point to authoritative specs, code, and evidence rather than copying their contents. Mark unverified claims and preserve exact commands or error text when they are needed to resume.

Complete with the saved note's path. Creating a note does not authorize launching another agent process, creating a new chat, or messaging another person.
